Project Description: What The Fork

What The Fork is a resturant review website that allows users to search for restaurants, view reviews, and submit their own reviews. The website is built using ASP.NET Web Forms and C#. It uses a SQL Server database to store restaurant information and user reviews. This website allows you to search by multiple cusines in the Pennsylvannia, New Jersey, and New York area. The dropdown shows you what restaurants are available in the area and allows you to view reviews and submit your own reviews. The website is built using ASP.NET Web Forms and C#. It uses a SQL Server database to store restaurant information, user reviews, and review ratings. The database design allows handles the logic of searching for food and how keep track of how reviews are calculated. The website design was laid out using bootstrap studio with the layout focusing on accesability. ease of use. and being mobile friendly.
